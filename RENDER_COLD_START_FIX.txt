RENDER COLD START FIX - APPLIED
================================

PROBLEM:
--------
Your Render free tier backend goes to sleep after 15 minutes of inactivity.
First request takes 50-60+ seconds to wake up (cold start).
This was causing timeout errors on your homepage for banners and categories.

SOLUTION APPLIED:
-----------------

1. ✅ Increased API timeout from 60s to 120s
   - File: frontend/js/api.js
   - This gives Render enough time to wake up

2. ✅ Added retry logic with better messaging
   - Files: frontend/pages/index.html (loadBanners, loadCategories)
   - Shows "Server may be waking up, please wait" message
   - Automatically retries once if timeout occurs
   - Falls back to default content if still fails

3. ✅ Created wake-up script
   - File: wake-server.js
   - Run before testing: node wake-server.js
   - This "warms up" the server so it loads fast

HOW TO USE:
-----------

Option 1: Wake server before testing
  node wake-server.js
  (Wait 50-60 seconds for first time)
  Then visit your site - it will load fast!

Option 2: Just visit the site
  - First load may take 60-90 seconds
  - You'll see "Server may be waking up" message
  - After that, it's fast for 15 minutes

Option 3: Keep server awake (recommended for production)
  - Use a service like UptimeRobot or Cron-job.org
  - Ping your backend every 10 minutes
  - URL to ping: https://mj-electricals.onrender.com/api/categories
  - This keeps it always awake

WHAT USERS WILL SEE:
--------------------
- Loading spinner with helpful message
- Automatic retry if timeout
- Default hero banner if server is slow
- Much better UX than before!
